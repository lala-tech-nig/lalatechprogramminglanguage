1. Philosophy — The Core Triad

LALA is built on three foundational pillars that distinguish it from every other programming language in existence:

🌍

Linguistic Sovereignty

Developers should never be forced to master a foreign language merely to express computational logic. LALA elevates Yorùbá, Hausa, and Igbo — three of Africa's most spoken languages — alongside English as first-class grammatical citizens. Every keyword, construct, and operator has a native equivalent.

⚡

Zero-Boilerplate Polyglot Reach

A new language cannot thrive in isolation. LALA provides instantaneous, transparent bridges to the two largest developer ecosystems: JavaScript/Node.js (npm) and Python 3.14 (PyPI). Import any npm package or Python library with a single line — no glue code, no marshaling.

🎯

Ergonomic Simplicity

LALA unites Python's conciseness with JavaScript's versatility. Clean brace-delimited blocks, optional semicolons, first-class logical keywords (and, or, not), and three dedicated for loop constructs make LALA immediately approachable.

2. Syntax & Grammar

LALA's syntax is modern, expressive, and tolerant of stylistic variation:

BlocksDelimited by curly braces { ... }. Indentation is aesthetic, not structural.
SemicolonsOptional at end of statements. Newlines serve as implicit terminators.
ParenthesesOptional around if, for, and while conditions when followed by a brace block.
CommentsSingle-line: // or #. Multi-line: /* ... */
EncodingFull UTF-8. Source files use NFKC normalization — accented and unaccented forms are equivalent.

3. The Multilingual Lexer

          
The heart of LALA's multilingual capability is its Unicode Lexer. It processes raw source text into a stream of canonical tokens that the parser understands uniformly, regardless of the input dialect.


          

            

              
1

              

                
NFKC Normalization

                
All source characters are normalized using Unicode NFKC — ensuring tẹ and te, or bikoṣe and bikose, are recognized identically.

              

            

            

              
2

              

                
Dialect Auto-Detection

                
LALA checks lala.config.json for dialect. If absent, it scans for signature vocabulary — Hausa markers like buga, aiki; Yorùbá markers like gbiyanju, otito.

              

            

            

              
3

              

                
Homograph Resolution

                
Critical for ko: In Hausa dialect it means OR. In Yorùbá it means NOT. The contextual detector disambiguates using the detected dialect.

              

            

            

              
4

              

                
Canonical Tokenization

                
All dialect variants map to the same internal token: fun, don, maka, and for all become KW_FOR. The parser sees only canonical tokens.

5. Tree-Walk Evaluator

          
LALA's runtime is a Tree-Walk Interpreter that traverses the AST and evaluates nodes directly. Key features:

          
    
            
  • Lexical Environments: Each block creates a new scope. Variable lookups walk up the scope chain.
    • 
            
  • First-class Functions: Functions capture their enclosing environment at creation — full closure semantics.
    • 
            
  • OOP Classes: Classes are runtime objects. init serves as the constructor. Method dispatch uses instance environments.
    • 
            
  • Async/Await: Event-loop concurrency via the V8 promise system — async fn returns a Promise.
    • 
            
  • Error Propagation: Exceptions bubble up through the call stack until caught by try/catch.
    •

8. Type System

          
LALA is dynamically typed with runtime type reflection. All values carry a type tag inspectable via type(val).


          

            
NumberIEEE 754 64-bit float. e.g. 42, 3.14

            
StringUTF-8 immutable. Template literals: "Hello ${name}"

            
Booleantrue/false and 4-language equivalents

            
Nullnull, ofo, babu, efu

            
ListDynamic ordered arrays: [1, "a", true]

            
ObjectKey-value maps: { name: "Ade" }

            
FunctionFirst-class closures, arrow functions (x) => x*2

            
ClassOOP blueprints with init constructor

            
JSProxyTransparent wrapper around JS objects

            
PyProxyTransparent wrapper around Python objects

          

        


        
        

          
9. Source-to-Source Dialect Translator

          
LALA includes a built-in bidirectional source-to-source translator. It takes any .lala file and rewrites all keywords while preserving identifiers, strings, and structure.

10. Memory Model & Runtime Security

          
LALA leverages V8's high-performance garbage collector (generational mark-and-sweep) for automatic memory management.


          
    
            
  • Heap allocation: All LALA objects (lists, maps, closures) live on V8's managed heap.
    • 
            
  • GC lifecycle: Objects become eligible for collection when no references exist — including cross-language proxy cleanup.
    • 
            
  • Python proxy lifecycle: When a PyProxy loses its last LALA reference, a finalization message is sent over the IPC channel to decrement the Python refcount.
    • 
            
  • Sandboxed mode: Run with --safe to disable filesystem writes and restrict FFI loading.
    • 
            
  • Explicit permissions: allow_js and allow_python in lala.config.json control interop access.
    •
