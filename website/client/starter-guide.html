📦 Installation

LALA runs on the V8 engine via Node.js. Install Node.js 18+ first if you don't have it, then install LALA.

Prerequisites

⚙️
Node.js 18+

Required for the V8 runtime and JS interop

nodejs.org →
🐍
Python 3.9+ (optional)

Required only for Python interop features

python.org →

Choose your platform

Terminal
# Install globally
npm install -g lala-lang

# Verify installation
lala --version
💡
On macOS/Linux you may need to prefix with sudo depending on your Node.js setup. Using nvm avoids this entirely.
  1. Download the Windows installer: Setup-Lala-v1.0.0-win.exe ↓
  2. Run the installer and follow the prompts. Node.js runtime is bundled.
  3. Open a new PowerShell or Command Prompt and run:
    lala --version
  4. You should see LALA v1.0.0. You're ready!
Terminal
# Via Homebrew (recommended)
brew tap lala-lang/lala
brew install lala

# Or download the .dmg installer
# from the Downloads page

# Verify
lala --version
Terminal
# Ubuntu / Debian
curl -fsSL https://deb.lala-lang.dev/setup.sh | sudo bash
sudo apt install lala

# Fedora / RHEL
sudo dnf install lala

# Arch Linux (AUR)
yay -S lala-lang

# Or via tarball
tar -xvf lala-v1.0.0-linux.tar.gz
sudo mv lala /usr/local/bin/

Verify your installation

Terminal
$ lala --version
LALA v1.0.0 (V8 12.3.219.11)

$ lala --help
Usage: lala [command] [file] [options]

Commands:
  run <file>         Run a .lala file
  translate <file>   Translate to another dialect
  check <file>       Type-check without running
  init               Create a new lala.config.json
  --version          Show version

🚀 Your First LALA Program

Let's write a classic "Hello, World!" to confirm everything works. We'll do it in all 4 dialects.

How it works

📄
Create file
hello.lala
✍️
Write code
Any dialect
▶️
Run it
lala run hello.lala
🎉
See output
Hello, World!

Choose your dialect

🇬🇧English--dialect en
// hello.lala
let name = "World"
print("Hello, " + name + "!")
🇳🇬Yorùbá--dialect yo
// kaabo.lala
jẹ orukọ = "Àgbáyé"
sọ("Ẹ káàbọ̀, " + orukọ + "!")
🇳🇬Hausa--dialect ha
// barka.lala
bari suna = "Duniya"
nuna("Sannu, " + suna + "!")
🇳🇬Igbo--dialect ig
// nnoo.lala
were aha = "Ụwa"
bịpụta("Nnọọ, " + aha + "!")

Run it

Terminal
# Auto-detects dialect from the file
$ lala run hello.lala
Hello, World!

# Force a specific dialect
$ lala run hello.lala --dialect yo
Ẹ káàbọ̀, Àgbáyé!
💡
Skip the install! Try any code snippet right now in the browser playground → — no setup required.

🌍 Understanding Dialects

LALA's dialect system lets you write the entire language — keywords, operators, even error messages — in your preferred language. Dialects are functionally identical; the runtime makes zero distinction.

Setting your dialect

lala.config.json
{
  "dialect": "yoruba",
  // Options: "english" | "yoruba" | "hausa" | "igbo"

  "interop": {
    "js": true,
    "python": true
  },
  "version": "1.0.0"
}

Translate between dialects

Terminal
# Translate a file from English to Yoruba
$ lala translate app.lala --to yo --out app_yoruba.lala

# Translate to all dialects at once
$ lala translate app.lala --to all

# In-place translation (overwrites original)
$ lala translate app.lala --to ha --in-place

📖 Language Basics

All examples below use English dialect for clarity. Every keyword has an equivalent in Yorùbá, Hausa and Igbo.

Variables & Types

variables.lala
// Immutable (constant)
let name = "Emeka"

// Mutable
var score = 0
score = 42

// Types: string, number, bool, null, list, map
let isActive = true
let items = ["one", "two", "three"]
let config = { "host": "localhost", "port": 8080 }

Control Flow

control.lala
// If / else
if score > 90 {
  print("Excellent!")
} else if score > 60 {
  print("Good job!")
} else {
  print("Keep going!")
}

// For loop
for i in 1..5 {
  print("Count: " + i)
}

// While loop
var n = 0
while n < 3 {
  print("n = " + n)
  n = n + 1
}

Functions

functions.lala
// Basic function
function greet(name) {
  return "Welcome, " + name + "!"
}

print(greet("Aisha"))  // Welcome, Aisha!

// Arrow-style (shorthand)
let double = (x) => x * 2

// Async function
async function fetchData(url) {
  let res = await js.fetch(url)
  return res.json()
}

Classes & OOP

person.lala
class Person {
  init(name, age) {
    this.name = name
    this.age = age
  }

  greet() {
    return "I am " + this.name + ", age " + this.age
  }
}

let p = new Person("Fatima", 25)
print(p.greet())
// I am Fatima, age 25

⚡ JS & Python Interop

One of LALA's superpowers: zero-boilerplate access to the world's two largest ecosystems.

JavaScript Interop

Since LALA runs inside the V8 engine, JS interop is native — no serialization, no overhead.

js_example.lala
// Access any JS global directly
let pi = js.Math.PI
print(pi)  // 3.141592653589793

// Import any npm package
import js "axios" as axios

async function main() {
  let res = await axios.get("https://api.github.com")
  print(res.data.current_user_url)
}

main()

Python Interop

Python runs as a subprocess communicating over JSON-RPC IPC. LALA returns transparent proxy objects.

ml_example.lala
// Import Python library
import py "numpy" as np

let arr = np.array([1, 2, 3, 4, 5])
print(np.mean(arr))   // 3.0
print(np.std(arr))    // 1.4142...

// Run arbitrary Python code
let result = py.eval("sum([x**2 for x in range(10)])")
print(result)  // 285
💡
Python path: Make sure python3 is on your PATH. Set a custom path in lala.config.json with "pythonPath": "/usr/bin/python3".

💻 CLI Reference

The lala command-line tool gives you everything you need to run, build, test, and translate LALA programs.

CommandArguments / FlagsDescription
lala run<file> [--dialect] [--safe]Execute a .lala file
lala check<file>Static type/syntax check without running
lala translate<file> --to <dialect> [--out] [--in-place]Translate between dialects
lala init[--dialect] [--with-python]Create lala.config.json in current dir
lala repl[--dialect]Start interactive REPL session
lala build<file> --out <dir>Bundle into a standalone executable
lala fmt<file|dir>Auto-format source files
lala test[--coverage]Run unit tests in the project
lala --version—Print version and runtime info
lala --help—Show help for any command
